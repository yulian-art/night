# 向星而行 · 自制角色资产

用 Blender 5.1 手工建模的首批角色资产，按《向星而行》设计文档的配色与「圆润低模、温暖童话感」风格制作。

## 文件

| 文件 | 部件数 | 说明 |
|---|---|---|
| `astronaut.glb` | 16 | 主角宇航员（小小旅人）：大白头盔 + 深蓝大面罩（金色描边）、生命维持背包（金色发光条）、橙色围巾 |
| `fox.glb` | 15 | 拾光狐狸（带路伙伴）：大三角耳朵、蓬松大尾巴带奶白尾尖、奶白胸毛 |
| `starjourney_heroes.blend` | — | Blender 源工程（两角色 + 灯光场景） |

## 重要：这两个模型当前不是正式角色

它们是**静态部件拼装**（16 / 15 个独立网格物件），**无骨骼、无动画**，并且实测尺寸与原点不满足 UE 角色要求：

| 实测 | 值 |
|---|---|
| 宇航员 | 高 2.24 m（Pawn 胶囊只有 1.80 m）；脚底 `z = −0.18`；面朝 **+X** |
| 狐狸 | 高 1.60 m；脚底 `z = −0.14`；面朝 **+X** |

正式角色改用第三方 **CC0 已绑定带动画**资产，见 [`art/thirdparty/LICENSE.md`](../../../../art/thirdparty/LICENSE.md)。

这两个模型保留为**源真值**与**可选的重定向目标**：若日后要把 CC0 的骨骼与动画重定向回自制造型，UE 侧无需改动。完整管线见 [从 Blender 建模到 UE 运行 · 实现方案](../../../../docs/从Blender建模到UE运行实现方案.md)。

## 导入 UE（若将来使用）

`glb` 可直接拖入 UE 5.8 内容浏览器（UE5 内置 glTF 导入）。**注意**：模型按公制（米）建模，而 UE 1 单位 = 1 cm，导入前需要 ×100；同时必须先修原点（原点在脚、Z=0）与朝向（转到面朝 −Y 再导出）。材质随模型自带，为纯色 + 自发光。
